## 🏆 Challenge Format

Each challenge is designed around a simple idea:

```text
💡 IDEA
   ↓
🧠 CODE
   ↓
🧪 TEST
   ↓
🎬 YOUTUBE VIDEO
   ↓
🚀 CHALLENGE COMPLETE
```

Some challenges focus on **speed**, some on **code length**, and others on simply building something cool.

## 🎯 Challenge Rules

Most challenges follow a few simple rules:

* 🧠 Build something from scratch
* ⏱️ Keep the solution simple
* 💻 Use the specified programming language
* 🚫 Avoid unnecessary libraries when possible
* 🔍 Test the code before publishing
* 🎬 Document the challenge on YouTube
